# Ethics & Data Handling

## Participant protection
- Participation is voluntary and anonymous.

- No personally identifying information (PII) is collected.
- Participants can skip questions or stop at any time.

## Sensitive topic note
The project discusses inequality, which may be emotionally sensitive. Messages will be written in a respectful, non-inflammatory tone.

## Data handling
- Raw data will be stored privately (not pushed to public GitHub).
- Public repo will contain only:
  - synthetic example data, or
  - aggregated results (no individual rows).

## Transparency
All materials (stimuli, survey items, analysis code) will be versioned and documented.
