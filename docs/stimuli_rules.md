# Stimuli Rules (v1)

## Goal
Make messages comparable so differences in outcomes are caused by *message type*, not random differences.

## Rules
- Target length: 140–170 words each
- Tone: calm, respectful, non-inflammatory
- Reading level: roughly Grade 8–10
- Format: plain text (no charts for v1)
- Topic: all inequality messages refer to the same inequality domain (wealth, White vs Black)
- Structural message includes: (a) systems/policy framing + (b) at least one numeric reference
- Narrative message includes: a personal story and avoids heavy statistics
