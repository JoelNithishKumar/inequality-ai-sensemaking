# Project Overview

## One-sentence summary
This project tests how message type (AI vs human, structural/data vs narrative) changes people’s beliefs about inequality and their support for solutions.

## Conditions (message types)
1) Structural + data (human-written)
2) Narrative story (human-written)
3) Hybrid (story + structural/data)
4) AI-written explanation (controlled constraints)
5) Neutral control (unrelated topic)

## Conditions (locked for v1)

1) structural_data
- Explains inequality mainly using systems/policy/structures and includes at least 1 numeric fact.

2) narrative_story
- Explains inequality using a short personal story with minimal/no numbers.

3) hybrid
- Begins with a story, then connects it to systems/policy and includes at least 1 numeric fact.

4) ai_explanation
- Explanation generated with AI under constraints (same length, calm tone, no extreme language).
- Content is controlled to match the same topic and structure goals.

5) control
- Neutral message unrelated to inequality (used to measure natural change over time).


## Study method (simple)
Pre-survey → Read one randomly assigned message → Post-survey

## Deliverables
- Stimuli set (v1 → v2 finalized)
- Survey (v1 → pilot → final)
- Python analysis notebook + scripts
- Short report with figures
- Reproducible repo with runbook
